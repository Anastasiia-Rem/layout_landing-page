# Nothing Landing Page

A responsive landing page based on the Nothing design.  
The project includes a header, burger menu, product recommendations, product categories, an about section and contact form.

## Technologies used

- HTML5
- SCSS
- BEM methodology
- JavaScript
- Parcel
- Responsive design
- CSS animations and transitions
